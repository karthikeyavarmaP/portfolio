# Karthikeyavarma — Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Publish with GitHub Pages

1. Open the repository Settings.
2. Select Pages from the sidebar.
3. Under Build and deployment, choose Deploy from a branch.
4. Choose `main` and `/(root)`, then save.
5. Wait for the deployment to finish. The site should be available at https://karthikeyavarmaP.github.io/portfolio/.

Before using this portfolio for applications, verify every project description and add links to public project repositories where available.
